# Homebrew tap

Free, open source Mac apps by [Herman Harazha](https://geragaraza.com/apps/). Apple silicon, macOS 13 or later.

```sh
brew install geragarazagh/tap/hex
brew install geragarazagh/tap/ocr
brew install geragarazagh/tap/stt
brew install geragarazagh/tap/tts
brew install geragarazagh/tap/holdq
brew install geragarazagh/tap/retyper
brew install geragarazagh/tap/pixlift
brew install geragarazagh/tap/grids
```

- [#HEX](https://github.com/geragarazagh/hex): color picker, a keyboard shortcut copies any pixel of the screen as a HEX code.
- [OCR](https://github.com/geragarazagh/ocr): screen text and QR codes to the clipboard.
- [STT](https://github.com/geragarazagh/stt): offline dictation with local speech recognition models.
- [TTS](https://github.com/geragarazagh/tts): text to speech with Siri and other macOS voices.
- [HoldQ](https://github.com/geragarazagh/holdq): ⌘Q quits an app only when held for a second.
- [Retyper](https://github.com/geragarazagh/retyper): text typed in the wrong keyboard layout, retyped in the right one.
- [Pixlift](https://github.com/geragarazagh/pixlift): screenshots and screen recording, each saved to the Desktop and copied to the clipboard at once; text and color from the screen.
- [Grids](https://github.com/geragarazagh/grids): grid overlay for checking layout and proportion.

Each app updates itself through Check for Updates, so `brew upgrade` leaves it alone. `brew uninstall --zap <name>` removes the app and its settings.
