# Homebrew tap

Mac apps by [Herman Harazha](https://geragaraza.com/apps/).

```sh
brew install geragarazagh/tap/grids
brew install geragarazagh/tap/stt
brew install geragarazagh/tap/copia
brew install geragarazagh/tap/pixlift
brew install geragarazagh/tap/retyper
brew install geragarazagh/tap/fully
brew install geragarazagh/tap/merum
brew install geragarazagh/tap/tts
brew install geragarazagh/tap/holdq
brew install geragarazagh/tap/hex
brew install geragarazagh/tap/ocr
```

- [Grids](https://github.com/geragarazagh/grids): grid overlay.
- [STT](https://github.com/geragarazagh/stt): dictation.
- [Copia](https://github.com/geragarazagh/copia): clipboard manager.
- [Pixlift](https://github.com/geragarazagh/pixlift): screenshots and screen recording.
- [Retyper](https://github.com/geragarazagh/retyper): keyboard layout fixer.
- [Fully](https://github.com/geragarazagh/fully): window maximizer.
- [Merum](https://github.com/geragarazagh/merum): plain-text notes.
- [TTS](https://github.com/geragarazagh/tts): text to speech.
- [HoldQ](https://github.com/geragarazagh/holdq): quit protection.
- [#HEX](https://github.com/geragarazagh/hex): color picker.
- [OCR](https://github.com/geragarazagh/ocr): screen text recognition.
